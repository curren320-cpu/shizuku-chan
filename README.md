# しずくちゃん（shizuku-status）

Claude の作業中、チャットの横に「しずくちゃん」が出てきて、いま何をしているかをアニメで見せてくれる mod です。
ファイルを読んでいるときは「よみよみ中」、コードを書いているときは「カタカタ…」、終わったら「できた！」と跳ねます。
下には、さっきまでやった作業が日本語で並びます。パネルを閉じたときは `/shizuku` で開き直せます。

## インストール

ターミナルの Claude Code で：

```
/plugin install shizuku-status --marketplace curren320-cpu/shizuku-chan
```

シェルから：

```
claude plugin install shizuku-status --marketplace curren320-cpu/shizuku-chan
```

デスクトップアプリでは、入力欄の横の + → Plugins → Add marketplace に `curren320-cpu/shizuku-chan` を入れ、Add plugin を押します。
